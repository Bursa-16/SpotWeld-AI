# Product Roadmap

## v1.2 — Repository and documentation baseline
- GitHub governance, architecture documentation, CI, and release discipline.

## v1.3 — Failure probability calibration
- Calibration datasets.
- Probability calibration curves.
- Material-family validation packs.
- Confidence intervals and calibration reports.

## v1.4 — Advanced parameter recommendation
- Minimum-change optimization.
- Constraint-aware recommendations.
- Multi-pulse recommendation rules.
- Electrode and cooling constraints.

## v1.5 — Norm and OEM rule packages
- Versioned customer/OEM rules.
- Rule conflict resolution.
- Source traceability and approval workflow.

## v1.6 — Production data integration
- CSV/Excel bulk analysis.
- REST import.
- OPC-UA/MQTT adapter interfaces without embedding image processing.

## v2.0 — Enterprise release
- Multi-tenant deployment.
- Audit-complete approvals.
- Validated model packages.
- On-premise installer and backup/restore tooling.
