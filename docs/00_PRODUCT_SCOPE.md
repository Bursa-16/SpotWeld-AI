# Product Scope

## Product identity
Spot Welding Parameter Analysis is an independent commercial product.

## Included
- Parameter entry and bulk import
- Material and stack-up evaluation
- Parameter range recommendation
- Nugget prediction
- Weld-lobe and DOE support
- Rule/norm compliance
- Potential failure probability analysis
- WPS-style engineering records
- Revision, test, and approval workflows

## Explicitly excluded
- Camera acquisition
- Uploaded-image inspection
- OpenCV
- YOLO detection or segmentation
- CNN-based image classification
- Visual defect localization

Those functions belong to the separate Spot Welding Image Processing product.

## Primary users
- Welding engineers
- Process engineers
- Quality engineers
- Manufacturing engineers
- Supplier quality engineers
- OEM/Tier-1 technical reviewers
