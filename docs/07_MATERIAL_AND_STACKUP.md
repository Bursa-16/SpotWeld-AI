# Material and Stack-Up Architecture

Each material family must have a dedicated rule package or engine adapter:
- Mild/medium carbon steel
- Coated steel
- AHSS/UHSS/PHS
- Stainless steel
- Aluminum
- Superalloy
- Dissimilar stack

A universal formula must not be treated as equally valid for every family.

Stack-up analysis includes:
- minimum thickness
- maximum thickness
- total thickness
- thickness ratio
- number of interfaces
- coating distribution
- adhesive presence
- layer order
