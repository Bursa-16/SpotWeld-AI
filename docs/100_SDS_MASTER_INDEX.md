# Non-Authoritative Legacy SDS Index Pointer

This file is retained only to prevent ambiguity from the historical duplicate
`docs/100_SDS_MASTER_INDEX.md` path.

The sole authoritative SDS master index and document-number allocator is:

[`../100_SDS_MASTER_INDEX.md`](../100_SDS_MASTER_INDEX.md)

This legacy pointer:

- does not allocate or reserve SDS document numbers;
- does not define document titles, paths, owners, statuses, or approvals;
- does not approve, supersede, or retire any document; and
- must not be treated as a synchronized mirror of the authoritative index.

All SDS registration and governance decisions must be read from the root index.
