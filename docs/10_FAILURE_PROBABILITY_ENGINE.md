# Failure Probability Engine

## Current failure modes
1. Expulsion / metal splash
2. Insufficient fusion
3. Small nugget
4. Excessive indentation
5. Electrode sticking
6. Accelerated electrode wear
7. LME / surface crack risk
8. Coating damage
9. Shunt-related instability
10. Cooling-related instability

## Result contract
Each mode returns:
- probability
- probability percent
- confidence
- severity
- dominant contributors
- validation tests
- recommended actions

## Calibration requirement
Current probabilities are engineering priors. Customer-specific field data is
required before interpreting them as observed defect frequencies.
