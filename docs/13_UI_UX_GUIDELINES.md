# UI/UX Guidelines

## Main screens
- Login
- Dashboard
- Projects
- Project detail
- Weld-point wizard
- Parameter analysis
- Failure probability
- Weld lobe
- Optimization
- Norm compliance
- Tests and approvals
- Reports
- Administration

## Result presentation
Never show only a score. Show:
- result,
- confidence,
- dominant factors,
- source,
- limits,
- recommended validation,
- recommended next action.
