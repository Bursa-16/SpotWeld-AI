# Coding Standards

## Python
- Type hints for public functions
- Pure domain functions where possible
- Pydantic at API boundaries
- SQLAlchemy repositories for persistence
- No equations inside route handlers

## TypeScript
- Strict mode
- Typed API contracts
- Reusable form and result components
- No business calculations in UI code

## Engineering
- Units in names or schemas
- Traceable sources
- No invented coefficients
- Explicit model validation status
