# Data Calibration and Validation

## Required fields
- exact input parameters
- material and coating
- stack order and thickness
- equipment and electrode
- measured nugget
- physical test result
- defect mode
- operator/station/date
- data quality status

## Metrics
- RMSE
- MAE
- bias
- R²
- calibration curve
- confusion matrix for probability thresholds
- false-negative rate for critical modes
