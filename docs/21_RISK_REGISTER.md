# Technical Risk Register

| Risk | Impact | Mitigation |
|---|---:|---|
| Unvalidated probability percentages | High | Calibration datasets and confidence labels |
| Unit mismatch | High | API-level unit validation and regression tests |
| OEM rule copyright | High | Private rule packages; no public redistribution |
| Model extrapolation | High | Applicability ranges and warnings |
| Incorrect automatic approval | High | Mandatory human approval gates |
| Product scope mixing | Medium | Explicit exclusion of image processing |
