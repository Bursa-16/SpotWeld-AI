# Claude Review Guide

Use this repository as a code-review target, not as a product-vision exercise.

## Required review order
1. Run backend tests.
2. Build frontend.
3. Verify clean Docker startup.
4. Compare code against SRS and architecture.
5. Inspect engineering equations and units.
6. Inspect authentication and authorization.
7. Inspect persistence, migrations, and auditability.
8. Report defects with file, line, severity, evidence, and remediation.

## Do not
- Merge this project with Spot Welding Image Processing.
- Add YOLO, OpenCV, image upload, or camera workflows.
- Invent missing engineering coefficients.
- Describe unvalidated models as production-certified.
