# Glossary

- **Nugget:** Fused weld kernel between sheets.
- **Expulsion:** Ejection of molten metal during welding.
- **Shunt:** Current bypass through nearby conductive paths.
- **Squeeze:** Time between force application and weld current.
- **Hold:** Time force remains after current ends.
- **LME:** Liquid metal embrittlement.
- **Weld lobe:** Acceptable current-time process window.
- **Stepper:** Current compensation profile for electrode wear.
- **WPS:** Welding procedure specification.
